### 🤖 Développement assisté par IA

Je n'apprends pas seulement à demander du code à un modèle : j'apprends à l'utiliser
dans un **processus d'ingénierie contrôlé** — spécifier avant de générer, contraindre
le format de sortie, valider automatiquement ce qui peut l'être, relire le reste,
et mesurer le résultat.

Deux traces publiques de cette discipline :

- une **charte d'usage** écrite dès la semaine 1, qui définit ce que je délègue et ce que je ne délègue jamais ;
- un **journal hebdomadaire** où je note ce que l'IA m'a fait gagner, ce qu'elle m'a fait perdre, et les erreurs que j'y ai détectées.

### 🚧 Deux projets fil rouge

**TaskFlow** — une seule application, construite et enrichie pendant tout le programme :
d'abord une bibliothèque Java, puis une API REST sécurisée, un déploiement cloud
automatisé, une interface React, et enfin un tableau de bord analytique.

| Étape | Dépôt | Statut |
|---|---|---|
| Bibliothèque métier Java | `taskflow-core` | ⚪ Démarre en semaine 3 |
| API REST Spring Boot | `taskflow-api` | ⚪ Démarre en semaine 9 |
| Déploiement cloud | `taskflow-cloud` | ⚪ Démarre en semaine 13 |
| Interface React | `taskflow-web` | ⚪ Démarre en semaine 18 |
| Tableau de bord analytique | `taskflow-analytics` | ⚪ Démarre en semaine 28 |

**devbuddy** — mon propre agent de développement logiciel, construit par versions
successives : analyse d'un besoin, génération de spécifications validées, planification,
génération de code et de tests, exécution contrôlée, documentation, puis interaction
avec Git et la CI. Chaque action irréversible passe par une validation humaine.

| Étape | Version | Statut |
|---|---|---|
| Analyse d'un besoin et spécifications validées (Java) | v0.1 – v0.2 | ⚪ Démarre en semaine 7 |
| Cœur Python, outils sandboxés, validation humaine | v0.5 – v0.7 | ⚪ Démarre en semaine 23 |
| Génération de code et de tests, debugging, coûts mesurés | v0.8 – v0.9 | ⚪ Démarre en semaine 26 |
| RAG, évaluation chiffrée, garde-fous de sécurité | v0.10 – v0.12 | ⚪ Démarre en semaine 34 |
| Orchestration complète du cycle | v1.0 | ⚪ Semaine 43 |
