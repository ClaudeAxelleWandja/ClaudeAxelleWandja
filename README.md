Une seule application, construite et enrichie pendant tout le programme :
d'abord une bibliothèque Java, puis une API REST sécurisée, une interface React,
un déploiement cloud automatisé, et enfin un tableau de bord analytique.

| Étape | Dépôt | Statut |
|---|---|---|
| Bibliothèque métier Java | `taskflow-core` | ⚪ Démarre en semaine 4 |
| API REST Spring Boot | `taskflow-api` | ⚪ Démarre en semaine 13 |
| Déploiement cloud | `taskflow-cloud` | ⚪ Démarre en semaine 17 |
| Interface React | `taskflow-web` | ⚪ Démarre en semaine 23 |
